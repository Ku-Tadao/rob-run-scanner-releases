# ROB RUN Scanner downloads

ROB RUN Scanner is an unofficial Windows overlay for the Steam version of ROB RUN. It marks visible inventory slots with **KEEP**, **USE**, or **SELL**.

## Install or update

1. [Open the latest free Windows release](https://github.com/Ku-Tadao/rob-run-scanner-releases/releases/latest).
2. Download **ROB.RUN.Scanner_x64-setup.exe**. If you use the reporting build, download **ROB.RUN.Scanner_x64-beta-setup.exe** instead.
3. Run the installer. Installing over an earlier version preserves your collection settings and cached data. If Windows SmartScreen prompts about the unsigned installer, confirm you downloaded it from the release above before choosing **More info** and **Run anyway**.
4. Launch the Scanner and ROB RUN. Use borderless or windowed mode with the game's default UI scale. If prompted, select the folder containing `ROB RUN_Data`.

The first icon scan takes about a minute. The app extracts item icons from your Steam install and stores them on your PC. Press **F8** to toggle the overlay and hold **Shift** over a marked slot for details.

## Support

The overlay reads the Bag, open containers, the Fence sale grid, vehicle Trunk and Cargo. Bag and open safe were verified on native 1080p, and support varies by grid and resolution. If something looks wrong, describe the grid, resolution and game UI scale in [a support issue](https://github.com/Ku-Tadao/rob-run-scanner-releases/issues/new). For an overlay issue, use **Overlay → Save debug log** and review the file before attaching it.

This repository hosts the free Windows installers, signed update manifest and derived item catalog. ROB RUN is developed and published by Kefir.
